# Мобильное приложение «Кибергород» (DualCode)

Обучающий игровой симулятор для подростков 12–17 лет, знакомящий с базовыми концепциями программирования на Python (Тема: Условия и ветвления). Разработано в рамках Всероссийского хакатона «ИТ-Прорыв».

## Ключевые особенности
* **Связный маршрут:** 3 последовательных интерактивных урока (if -> if-else -> операторы сравнения).
* **Сюжетная геймификация:** Восстановление районов Нео-Сити, прокачка до 150 XP и сбор цифровых ключей доступа.
* **Доступность:** Короткие, понятные лекции крупным шрифтом встроены прямо перед практическими тестами.

## Технический стек
* **Язык:** Kotlin
* **Интерфейс:** Jetpack Compose (Declarative UI)
* **Прогресс:** Локальное сохранение кэша через Preferences DataStore
  
* ## Как запустить приложение

### ⚠️ Важно для жюри (Выбор файла):
В папке сборки генерируются два файла. Устанавливать нужно строго **app-debug.apk** (это готовый игровой прототип). Файл *app-debug-androidTest.apk* является служебным и используется только для запуска инструментальных тестов в среде разработки.

### Вариант 1: Быстрый запуск на смартфоне (Рекомендуемый)
1. Скачайте и перенесите файл **app-debug.apk** на ваш Android-смартфон.
2. В настройках телефона разрешите установку приложений из неизвестных источников.
3. Установите APK и запустите симулятор «Кибергород».
